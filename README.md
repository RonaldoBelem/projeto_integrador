
# Projeto Integrador

Este projeto consiste em um site focado em **saúde e bem-estar**, desenvolvido com o objetivo de fornecer informações relevantes sobre cuidados com a saúde, estilo de vida, e promover a interação entre usuários por meio de uma comunidade online.

## Funcionalidades

- **Página Inicial**: Exibe destaques de artigos recentes e relevantes.
- **Artigos**: Publicações sobre temas como bem-estar, saúde mental, cuidados médicos e estilo de vida.
- **Comunidade**: Área destinada à troca de experiências entre os usuários.
- **Login**: Sistema de autenticação para acesso à comunidade e funcionalidades restritas.
